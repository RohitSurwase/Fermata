# 02 — Module Breakdown

> ⚠️ **Describes the full UPSTREAM codebase.** Many modules listed here are **removed from the current
> build** (only `:fermata, :utils, :exoplayer, :vlc, :web` build now). Removed module dirs still exist
> on disk but are excluded in `settings.gradle`. See `Knowledge/PROJECT_STATE.md` for the live state.

> File-by-file breakdown grounded in source. Signatures and responsibilities were read from the
> actual files. Detailed per-feature-module documentation is split into `Knowledge/modules/*.md`
> and indexed in §4 below. Source-file counts per module (excluding `build/`):
>
> `:fermata` 140 · `:utils` 234 · web 16 · tv 15 · felex 13 · poi 8 · cast 5 · chat 4 ·
> exoplayer 4 · opusmt 3 · vlc 2 · whisper 2 · gdrive 1 · mlkit 1 · sftp 1 · smb 1

## 1. `:fermata` application module — `me.aap.fermata`

### 1.1 Root package
- `FermataApplication.java` — `Application` subclass (`NetSplitCompatApp`). Owns `FermataVfsManager`,
  `BitmapCache`, `SharedPreferenceStore` ("fermata"), `AddonManager`. Handles locale wrapping in
  `attachBaseContext`, Android-Auto mirroring service binding (`setMirroringMode`). `get()` returns the
  singleton. See `01_architecture_overview.md §3`.
- `BuildConfig` (generated) — exposes `AUTO`, `D`, `ENABLE_GS`, `APPLICATION_ID`, and `ADDONS`
  (`AddonInfo[]`, generated by `build.gradle`).

### 1.2 `addon/` — addon framework
| File | Type | Responsibility |
|---|---|---|
| `FermataAddon.java` | interface | Base SPI. `getAddonId():@IdRes`, `getInfo():AddonInfo`, lifecycle `install/uninstall/start/stop`, `handleIntent(MainActivityDelegate,Intent)`, static `findAddonInfo(String)` scanning `BuildConfig.ADDONS`. |
| `AddonInfo.java` | class | Immutable descriptor: `moduleName`, `className`, `addonName`, `icon`, `order`, `hasSettings`, `isAuto`, `depends[]`, and an `enabledPref` (`Pref.b(className+"_enabled", ...)`). `isInstalled()` does `Class.forName`. `Comparable` by `order` then module name. |
| `AddonManager.java` | class | `BasicEventBroadcaster` + `PreferenceStore.Listener`. Loads enabled addons reflectively in ctor; `getOrInstallAddon(...)`, `install/uninstall(AddonInfo)` via `DynamicModuleInstaller`; dependency install; retry loop `scheduleLoadAddon` (up to 180 s). Maps addon by id, class name, module name. |
| `MediaLibAddon.java` | interface | Contributes `Item`s to the library: `getItem(lib,scheme,id)`, `isSupportedItem(Item)`. |
| `FermataContentAddon.java` | interface | Serves files through `FermataContentProvider`: `openFile(Uri)`, `getFileType(...)`. |
| `FermataFragmentAddon.java` | interface | `createFragment():ActivityFragment`. |
| `FermataActivityAddon.java` | interface | Activity lifecycle hooks. |
| `FermataMediaServiceAddon.java` | interface | `onServiceCreate/Destroy(MediaSessionCallback)`. |
| `FermataToolAddon.java` | interface | Toolbar contribution. |
| `TranslateAddon.java` | class | Built-in (not a dynamic module) translation addon facade. |
| `SubGenAddon.java` | class | Subtitle generation (speech→text). Defines prefs `ENABLED`, `LANG`, `CHUNK_LEN`, a `Transcriptor` contract used by `SpeechRecognitionService`; depends on `exoplayer,translate`. |

### 1.3 `media/lib/` — content model (30 files)
Interface **`MediaLib.java`** defines the tree contract:
- Identity/config: `getRootId()`, `getContext()`, `getPrefs():MediaLibPrefs`, `getVfsManager()`,
  `getMediaEngineManager()`, `getMetadataRetriever()`, `getBitmapCache()`.
- Roots: `getFolders():Folders`, `getFavorites():Favorites`, `getPlaylists():Playlists`.
- Lookup (async): `getItem(CharSequence):FutureSupplier<? extends Item>`,
  `getLastPlayedItem():FutureSupplier<PlayableItem>`, `getCachedItem`, `getOrCreateCachedItem`.
- Browse-service bridge: `getChildren`, `getItem`, `search` (overloads adapting to
  `MediaBrowserServiceCompat.Result` via `MediaLibResult.Wrapper`).
- Nested item contracts: `Item`, `BrowsableItem`, `PlayableItem`, `Folders`, `Favorites`,
  `Playlists`, `Playlist`.

Implementations / item types:
| File | Role |
|---|---|
| `DefaultMediaLib.java` | Root impl; owns engine manager, metadata retriever, item cache; dispatches `getChildren/getItem/search`; `cleanUpPrefs`, `clearCache`. |
| `ItemBase.java` / `BrowsableItemBase.java` / `PlayableItemBase.java` | Abstract bases for items. |
| `ItemContainer.java` | Base for containers holding ordered children with prefs. |
| `FolderItem.java` / `FileItem.java` | File-system folders/tracks (via VFS). |
| `CueItem.java` / `CueTrackItem.java` | CUE-sheet album + virtual tracks. |
| `M3uItem.java` / `M3uTrackItem.java` / `M3uGroupItem.java` | M3U playlist parsing/items. |
| `DefaultFolders.java` | Root "Folders" node; user-added roots. |
| `DefaultFavorites.java` | Favorites list (prefs-backed). |
| `DefaultPlaylists.java` / `DefaultPlaylist.java` | User playlists. |
| `SearchFolder.java` | Virtual folder holding search results. |
| `ExtRoot.java` / `ExtBrowsable.java` / `ExtPlayable.java` | Addon-contributed items (TV, web, felex). |
| `ExportedItem.java` / `PlayableItemWrapper.java` / `StreamItemWrapper.java` | Wrappers/decorators. |

### 1.5 `media/service/` — media session (6 files)
| File | Role |
|---|---|

| `MediaSessionCallback.java` | **52 KB / `MediaSessionCallback` class lines 141–1622.** The playback state machine: implements `MediaSessionCompat.Callback`, drives the active `MediaEngine`, handles `onPlay/onPause/onStop/onSeekTo/onSkipTo*/onFastForward/onRewind/onPlayFromSearch/onCustomAction`, voice commands, favorites toggling, and publishes `PlaybackStateCompat`. ### 1.6 `ui/` — presentation (`activity`, `fragment`, `view`)
- `activity/MainActivity.java` + `MainActivityDelegate.java` (**44 KB, 1345 lines**) — the UI brain:
  navigation, fragment switching, control panel, video surface, permission requests
  (`checkPermissions`), intent handling, addon UI hooks. `MainActivityPrefs.java` holds UI prefs
  (theme, locale `Lang`, layout). `VoiceCommand` / `VoiceCommandHandler` implement spoken control.
- `fragment/` — `MediaLibFragment` (base list fragment), `FoldersFragment`, `FavoritesFragment`,
  `PlaylistsFragment`, `SettingsFragment` (**32 KB** — builds the entire settings tree incl. addon
  settings), `AudioEffectsFragment`, `SubtitlesFragment`, plus mediators
  (`ToolBarMediator`, `NavBarMediator`, `FloatingButtonMediator`).
- `view/` — custom views: `ControlPanelView` (**29 KB**), `VideoView` (**21 KB**),
  `AudioEffectsView` (**19 KB**), `MediaItemView`/`MediaItemListView`/adapters,
  `MediaItemMenuHandler` (**25 KB** context menus), `SubtitlesView`, `SplitLayout`, `BodyLayout`.

### 1.7 `action/`, `provider/`, `vfs/`, `util/`, `service/`
- `action/Action.java`, `Key.java`, `KeyEventHandler.java` — remote/keyboard key → action mapping
  (Android-TV / car).
- `provider/FermataContentProvider.java` — read-only `ContentProvider`. Two URI namespaces:
  `content://<app>/image/<base64>` (cover art; resolves `file/http/https/content/android.resource`
  via `BitmapCache`) and `content://<app>/addon/<name>/<base64>[/displayName]` (delegates to a
  `FermataContentAddon`). `insert/delete/update` are no-ops (returns input / 0). `query` returns a
  one-row `MatrixCursor` of display name + MIME.
- `vfs/FermataVfsManager.java`, `VfsProvider.java`, `VfsProviderBase.java` — bridges `me.aap.utils.vfs`
  providers to the app; `vfs/m3u/*` is a virtual FS exposing remote/local M3U playlists as resources.
- `util/Utils.java` — misc helpers (`getLauncherColor`, `getResourceUri`, `openUrl`, MIME helpers).
- `service/SpeechRecognitionService.java` — `RecognitionService`. Records 16 kHz mono PCM via
  `AudioRecord`, chunks it (`CHUNK_LEN=5 s`), and feeds a `SubGenAddon.Transcriptor` to produce
  segment/final results. Permission-gated on `RECORD_AUDIO`.

## 2. `:utils` library — `me.aap.utils` (234 files)

The reusable foundation. Highlights (full package list in `01_architecture_overview.md §4.1`):

- **`app/`** — `App` (base `Application`: thread pool, scheduler, main handler, crash log, VFS),
  `NetApp`, `SplitCompatApp`, `NetSplitCompatApp` (the one Fermata extends).
- **`async/`** — hand-rolled async primitives. `FutureSupplier<T>` (16 KB) is the core monadic
  future with `.then/.map/.main/.onSuccess/.onFailure/.cast`; `Promise`, `Completed` (static
  `completed/failed/completedVoid/completedNull/completedEmptyList`), `Async` (`retry`, iteration),
  `ObjectPool` (used for SFTP/SMB sessions), `PromiseQueue`, `CompletableSupplier`.
- **`vfs/`** — `VfsManager`, `VirtualFileSystem/Resource/File/Folder`, `NetFileSystemBase`
  (credential persistence — **weak hex "encryption", see audit**), providers `local`, `content`,
  `smb` (`SmbRoot`, `SmbFileSystem`, smbj-based), `sftp` (`SftpRoot`, `SftpFileSystem`, jsch-based,
  `SessionPool`), `gdrive` (`GdriveFileSystem`, `GdriveFolder`), `generic`.
- **`net/`** — `SelectorHandler` (26 KB NIO reactor), `NetHandler`, `NetChannel`, `SslChannelImpl`
  (18 KB TLS), `NetThreadPool`; `net/http/` custom HTTP; `net/ssdp/` UPnP/DLNA discovery.
- **`pref/`** — `PreferenceStore` (typed `Pref<T>` + `Listener` broadcast), `SharedPreferenceStore`,
  `BasicPreferenceStore`, `PreferenceSet`/`PreferenceView` (settings UI DSL), `PrefCondition`.
- **`security/`** — `SecurityUtils` (11 KB): BouncyCastle self-signed X.509 cert/keypair generation,
  hashing, used by the embedded TLS server/HTTP stack.
- **`io/`** — stream/channel utilities (`IoUtils`, `FileUtils`, `AsyncPipe`, `GunzipOutputStream`,
  `RandomAccessChannel`, `MemOutputStream` capped at half max-heap).
- **`ui/`** — `ActivityDelegate`/`ActivityBase` framework, fragments, overlay menus, custom views,
  notifications, `UiUtils` (16 KB).
- **`voice/`** — `SpeechToText`, `TextToSpeech` + exception types.
- **`db/SQLite.java`** — thin SQLite helper (used by metadata/felex caches).
- **`module/DynamicModuleInstaller.java`** — wraps Play `SplitInstallManager` for feature install.
- **`collection/`, `function/`, `holder/`, `text/`, `log/`, `concurrent/`, `event/`, `misc/`, `xml/`,
  `resource/`, `os/`** — supporting primitives (custom functional interfaces, `CollectionUtils`,
  `CacheMap`/`LruMap`, `TextUtils`/`SharedTextBuilder`, `Log`, thread pools, event broadcaster).

### 2.1 `:utils` tests (`depends/utils/src/test`)
JUnit4 unit tests exist for `async` (`PromiseTest`, `ObjectPoolTest`), `concurrent`
(`ConcurrentLinkedQueueTest`), `collection`, `io`, `net` (`NetHandlerTest`), `net/http`
(`HttpHandlerTest`), and `vfs`/`vfs/local`. The main `:fermata` module has a single test package
`me/aap/fermata/media/sub` (subtitle tests). Overall automated-test coverage is limited to the

## 3. Persistence overview

- **App content & settings:** typed prefs in `SharedPreferences("fermata")` and `"medialib"` via
  `SharedPreferenceStore`. Favorites, playlists, per-item playback position/speed/effects, folder
  roots, and addon enable-flags are all pref-backed (`media/pref/*`).
- **`media/pref/`** defines the schemas: `MediaPrefs`, `MediaLibPrefs`, `BrowsableItemPrefs`
  (sort masks), `PlayableItemPrefs` (position/bookmarks/audio-sub selection), `FoldersPrefs`,
  `FavoritesPrefs`, `PlaylistsPrefs`/`PlaylistPrefs`, `FolderItemPrefs`, `StreamItemPrefs`,
  `PlaybackControlPrefs`.
- **Metadata cache:** `MetadataRetriever` uses `me.aap.utils.db.SQLite` to cache extracted tags and
  artwork references (avoids re-scanning on every browse).
- **VFS credentials:** persisted by `NetFileSystemBase` as hex-encoded UTF-16 in prefs
  (`encrypt`/`decrypt` at lines 324–330, self-labeled "Weak encryption"). **Audit finding.**
